# 14 · Glosario

[← Índice del levantamiento](README.md)

Términos del negocio y del documento. Los marcados *(nuevo v4)* se agregaron en esta versión.

| Término | Significado en este documento |
| --- | --- |
| Activo | Equipo o componente identificable que pertenece a un cliente, a un sitio o a la empresa |
| ARCOTEL | Organismo regulador ecuatoriano de telecomunicaciones, ante el cual se tramitan las pólizas y los certificados de frecuencia |
| Baja técnica | Decisión de no reparar un equipo, por no ser reparable o por no ser rentable |
| Base fría | Lista de contactos importada solo para campañas; no entra al pipeline ni se asigna a asesores hasta que el contacto interactúa (LEAD-003, LEAD-004) *(nuevo v4)* |
| Cadena de custodia | Secuencia de eventos que registra quién tiene un equipo, quién lo recibe y cuándo |
| Campo personalizado | Campo que un administrador agrega a la ficha sin cambiar el software (CLI-018) *(nuevo v4)* |
| Canal | Configuración de una frecuencia dentro del plan de un cliente |
| Cliente | Organización o persona con relación comercial reconocida. En modo integrado, el cliente fiscal se sincroniza con el sistema contable |
| Código de color | Parámetro de identificación en redes digitales DMR |
| CTCSS y DCS | Sistemas de tono que permiten que un radio solo reciba a su grupo |
| Dealer | Distribuidor o mayorista al que se piden repuestos que no hay en almacén (T1) *(nuevo v4)* |
| Garantía tercerizada | Garantía otorgada por un proveedor externo que la empresa traslada al cliente final |
| Habilitación comercial | Conjunto de speech, puntos fuertes y respuestas a objeciones que apoya al asesor (M09) *(nuevo v4)* |
| Inbox | Bandeja común donde entran los contactos de todos los canales |
| Lead | Persona u organización potencial, aún no necesariamente calificada |
| Mensaje predeterminado | Mensaje o cadena de mensajes configurada en administración que se envía ante una fecha o un evento: cumpleaños, vencimiento, renovación (MKT-015) *(nuevo v4)* |
| Modo autónomo | Funcionamiento de la plataforma sin integración contable. Es el modo por defecto y con el que se construye (sección 4.2) *(nuevo v4)* |
| Modo integrado | Funcionamiento con el conector de UpConta activo: sincroniza y evita la doble captura, sin habilitar funciones que antes no existieran *(nuevo v4)* |
| Objeción | Reparo que el cliente pone durante la negociación, registrado por producto o categoría para analizarlo y responderlo (HAB-003) *(nuevo v4)* |
| Pipeline | Flujo de etapas por el que avanza una oportunidad o una relación de postventa |
| Plantilla semilla | Archivo con los datos iniciales de un catálogo, preparado desde el levantamiento para cargarlo en el sistema (ADM-014, `data/semillas/`) *(nuevo v4)* |
| POC | Modalidad de equipos mencionada por el cliente; su alcance exacto debe validarse |
| Proforma | Propuesta económica versionada. Vive en OMNITRONEC 360 |
| Proforma técnica | Propuesta derivada del diagnóstico, con el trabajo y los repuestos requeridos. Es el nombre que reemplaza a «informe técnico» (T1, DEC-008) |
| Prospecto | Lead con identidad y contexto suficientes para darle seguimiento |
| Puntos fuertes | Lista breve de lo que hay que comunicar sí o sí: dolores del cliente y cómo el producto los resuelve (HAB-002) *(nuevo v4)* |
| Ranura | División temporal que permite dos conversaciones sobre una misma frecuencia digital |
| Scoring | Puntuación calculada para priorizar. Debe ser siempre explicable |
| Semáforo | Valoración manual en verde, ámbar o rojo que refleja la percepción del asesor |
| Simplex y dúplex | Canal que transmite y recibe en la misma frecuencia, o en frecuencias distintas |
| Sitio | Ubicación física de un cliente, con su infraestructura y sus activos |
| SLA | Compromiso medible de respuesta o resolución, con reglas de pausa definidas |
| Speech | Guion de venta aprobado, por producto y por tipo de industria |
| T1, T2, T3, T4 | Las cuatro grabaciones de la reunión con el cliente: 12:38, 14:32, 16:16 y 16:55 *(nuevo v4)* |
| UpConta | Sistema contable seleccionado. En modo integrado es la fuente maestra fiscal y de inventario |
| UTM | Parámetros que identifican la fuente, el medio y la campaña de origen de un contacto. En la reunión se dijo «UTP» (T1) *(nuevo v4)* |
